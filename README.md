# 上毛かるた 練習アプリ

上毛かるたの札を覚えるための、ブラウザだけで動く学習アプリです。
React + Vite で作られていて、データベースは使いません。記録はブラウザのローカルストレージに保存されます。

## 機能

- **練習**: 札を1枚ずつ表示し、タップで裏面を確認します。並び順(あいうえお順/ランダム)と、最初に見る面(読み札/取り札)を切り替えられます。矢印キー(← →)でも移動できます。
- **テスト**: 読み札を見て、4択から正しい取り札を選びます。問題数は 10枚・20枚・全部から選べます。
- **記録**: 札ごとの正解回数・不正解回数を一覧で確認できます。テストで答えるたびに自動で加算されます。

## 札のデータを入力する

札の文言は `src/data/cards.js` に入力します。44枚分の枠(頭文字と `id`)は用意してあります。

```js
{ id: 'あ', kana: 'あ', yomi: '読み札の文言', tori: '取り札のことば', note: '' }
```

- `yomi` と `tori` の**両方**が入力された札だけが出題されます。
- 1枚も入力されていない間は、動作確認用のサンプル札(`src/data/cards.sample.js`)が表示されます。
- `id` は記録(ローカルストレージ)のキーです。あとから変えると、その札の記録が引き継がれません。

> **公開時の注意**: 上毛かるたの読み札・取り札の文言には著作権があります。
> GitHub で公開する前に、権利者(上毛かるた競技会など)の利用条件を確認してください。
> 文言を含めずにリポジトリを公開し、手元でだけデータを入力する方法もあります。

## 開発

```bash
npm install
npm run dev      # 開発サーバー
npm run build    # dist/ に本番ビルド
npm run preview  # ビルド結果の確認
```

Node.js 20.19 以上(または 22 以上)が必要です。

## GitHub Pages で公開する

1. このフォルダを GitHub のリポジトリに push します(ブランチ名は `main`)。
2. リポジトリの **Settings → Pages → Build and deployment → Source** を **GitHub Actions** にします。
3. `main` に push するたびに `.github/workflows/deploy.yml` が実行され、自動で公開されます。

`vite.config.js` の `base` を `'./'` にしてあるので、リポジトリ名を変えても設定の修正は要りません。

## 記録について

記録は、ブラウザのローカルストレージ(キー: `jomo-karuta:stats:v1`)に次の形式で保存されます。

```json
{ "あ": { "correct": 3, "wrong": 1, "last": "2026-10-13T01:23:45.000Z" } }
```

端末やブラウザをまたいだ共有はできません。ブラウザのサイトデータを消すと、記録も消えます。

## ディレクトリ構成

```
src/
  App.jsx               タブ切り替えと記録の管理
  components/
    Practice.jsx        練習モード
    Quiz.jsx            テストモード
    Stats.jsx           記録の一覧
  data/
    cards.js            札のデータ(ここを編集)
    cards.sample.js     動作確認用のサンプル
    index.js            出題対象の札を決める
  lib/
    storage.js          ローカルストレージの読み書き
    shuffle.js          シャッフル
```
